Built a production-grade, end-to-end field operations platform for a US-based grease recycling company — covering everything from customer management and route scheduling to real-time driver tracking and automated payout calculation.

🔧 Backend & Admin Panel (Laravel 12 + Filament v4):
• Multi-role access control (Admin, Dispatcher, Driver, Accounting) with granular Filament policies
• Full CRUD management for Customers, Locations, Routes, and Users — with CSV import/export
• Intelligent route scheduler that auto-generates daily stops based on service frequency and day-of-week rules
• Dispatch Dashboard with emergency stop management, stop reassignment, and real-time status tracking
• Automated payout engine calculating driver earnings per stop using configurable per-location rates
• Reports module with location-level stats, exportable CSVs, and accounting-ready summaries
• Google Maps embedded live preview in the location form (reactive address-to-map binding)
• Custom branded Filament theme (orange/dark palette aligned to company logo)

📱 Driver Web App (Vue 3 + Pinia + Vite):
• PWA-enabled mobile interface for drivers to view today's assigned route and stops
• Start/complete route run flow with real-time GPS stop tracking and status logging
• Offline-first architecture using IndexedDB (via idb) — works without network connectivity
• Pounds-collected logging, skip-reason capture, and duplicate pickup warnings
• JWT-authenticated REST API with Laravel Sanctum

📦 Android App (Capacitor + Remote Webview):
• Packaged as a native Android APK using Capacitor — loads live web app remotely from the production server
• Full Chrome DevTools debugging support via USB for on-device QA
• Signed release APK ready for Google Play Store or direct driver distribution

⚙️ Tech Stack:
Laravel 12 · Filament v4 · Vue 3 · Pinia · Vite · Capacitor · Laravel Sanctum · MySQL · PWA · IndexedDB · Apache (cPanel)

55 automated PHPUnit tests — all passing.
